## Featured Projects

### Pulse AI

**Heart Failure Readmission Prediction & Explainable AI**

Pulse AI is a machine learning system designed to predict the risk of heart-failure patient readmission after discharge.

I built the machine learning model and backend, engineered a synthetic dataset through reverse engineering, and integrated explainability so the system does not simply produce a prediction — it also provides insight into why that prediction was made.

#### What I Built

- Machine learning model using **XGBoost**
- **12,000 synthetic records × 35 features**
- Synthetic dataset engineering and generation
- FastAPI prediction backend
- SHAP-based model explainability
- ML model ↔ REST API integration
- Explainable readmission-risk assessment

#### Model Evaluation

| Metric | Result |
|---|---:|
| ROC-AUC | **~95%** |
| Accuracy | **~88%** |
| Precision | **~82%** |
| Recall | **~77%** |

> The estimated 10–30% potential reduction in readmissions represents a project impact target, not a clinically validated outcome.

**Technologies:** Python · XGBoost · SHAP · FastAPI · Synthetic Data

### Civic AI

**Agentic AI-Powered Civic Complaint Management**

Civic AI is a civic complaint registry designed to intelligently process, classify, route, prioritize, and monitor public complaints.

The system uses an **agentic AI orchestrator built with Lyzr AI Studio**, coordinating multiple specialized agents across the complaint lifecycle.

#### Agentic Workflow

- **Complaint Drafting Agent**  
  Converts broken or poorly written user input into a structured complaint.

- **Department Routing Agent**  
  Determines the appropriate department for the complaint.

- **Priority Agent**  
  Determines the priority of the complaint.

- **Timeline Agent**  
  Estimates how long the complaint should take to resolve.

- **Orchestrator**  
  Coordinates the specialized agents and manages the workflow.

- **Escalation Workflow**  
  Escalates unresolved complaints to the administrator when the assigned timeline expires.

#### Supported Departments

- Police
- Fire
- RTO
- Hospital
- Municipal

#### What I Built

- Multi-agent AI workflow
- Agent orchestration using **Lyzr AI Studio**
- Backend ↔ frontend integration
- Supabase database integration
- Authentication
- Admin panel
- Complaint lifecycle management

**Technologies:** Lyzr AI Studio · Agentic AI · Multi-Agent Systems · Supabase
